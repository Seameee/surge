vless脚本使用方法：

```bash
wget -O vless-server.sh https://raw.githubusercontent.com/Seameee/surge/main/vless-server.sh && chmod +x vless-server.sh && bash vless-server.sh
```
快捷命令
```bash
vless
```

nft脚本使用方法：
```bash
curl -L https://raw.githubusercontent.com/Seameee/surge/main/nft.sh -o nft.sh  
chmod +x nft.sh  
./nft.sh  
```

快捷命令：    
```bash  
nftm
```
